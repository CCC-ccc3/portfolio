# 小张 · 个人作品集

一个简洁的软件工程学生个人作品集网站，面向 AI 辅助开发 / 大语言模型应用方向，用于学业与求职展示。

## 功能简介

- **首页欢迎区**：个人介绍与项目入口，附轻科技风格装饰
- **项目作品**：展示 4 个代表项目（轻记账 · 微信小程序、拾光集市 · Web 应用、城市脉搏 · 数据可视化大屏、课语通 · AI 应用），左右交替版式
- **关于我**：个人简介
- **联系方式**：邮箱、微信、GitHub 等信息卡片
- **深浅色主题切换**：右上角悬浮按钮一键切换，选择通过 localStorage 记忆
- **交互细节**：锚点平滑滚动、导航随滚动自动高亮、区块滚动渐入、图片懒加载
- **响应式布局**：兼容桌面端、平板与移动端

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript（ES6）
- 不使用 React / Vue 等前端框架，不引入第三方 UI 组件库
- 主题基于 CSS 变量（`:root` 与 `html[data-theme="dark"]`）统一管理

## 目录结构

```
├── index.html          # 页面结构
├── css/style.css       # 全部样式（含深色主题变量）
├── js/
│   ├── main.js         # 交互逻辑（导航、渐入、懒加载、主题切换）
│   └── theme-init.js   # 主题预初始化，避免刷新闪烁
└── assets/images/      # 头像与项目示意图
```

## 运行方式

本项目为纯静态站点，无需安装依赖：

1. 直接双击打开 `index.html`；或
2. 启动本地静态服务器后访问，例如：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```
